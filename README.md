# Yandex Station Local Control API

Простая и быстрая библиотека для локального управления умными колонками Яндекса (Яндекс Станциями) по протоколу **Glagol**. 

Позволяет управлять воспроизведением, регулировать громкость, отслеживать текущий трек с обложкой и отправлять любые голосовые команды Алисе напрямую по локальной сети (Wi-Fi) — моментально и без облачных задержек.

---

## Возможности

- **Вход без паролей по QR-коду**: скрипт автоматически открывает QR-код в браузере — достаточно отсканировать его камерой телефона или в приложении Яндекс.
- **Автоматический поиск колонок**: скрипт сам находит все Станции в вашей домашней сети (через mDNS и сканирование портов).
- **Поддержка всех моделей**: Станция (1 и 2), Макс, Миди, Мини, Мини 2, Лайт, Модуль.
- **Пульт управления**: переключение треков, пауза, воспроизведение, точная регулировка громкости.
- **Голосовые команды и TTS**: отправка любого текста Алисе (например, *«включи радио»*, *«какая погода»*, *«поставь таймер»* или просто фразы для озвучки).
- **Мониторинг плеера**: получение статуса воспроизведения в реальном времени, названия трека, исполнителя и ссылки на обложку в высоком разрешении.

## Установка

Требуется **Python 3.9+**.

```bash
git clone https://github.com/blackalex1/yandex-station-Api.git
cd yandex-station-Api
pip install requests websockets zeroconf
```

## Использование

### 1. Первоначальная настройка
Запустите мастер настройки:
```bash
python yandex_setup_full.py
```
- В браузере откроется страница с QR-кодом.
- Отсканируйте его в приложении Яндекс, Алиса или камерой телефона и подтвердите вход.
- Скрипт автоматически найдет ваши колонки в сети и сохранит настройки.
- В конце можно сразу отправить тестовую фразу на выбранную колонку.

---

### 2. Пульт управления
Запустите интерактивный пульт:
```bash
python test_music_control.py
```
Выберите нужную колонку и действие:
1. **Следующий трек** (`next`)
2. **Предыдущий трек** (`prev`)
3. **Пауза** (`stop`)
4. **Воспроизведение** (`play`)
5. **Громкость** (`setVolume`, шкала от 0 до 10)
6. **Команда Алисе / Озвучить текст** (`sendText`) — выполняет любую команду или озвучивает введенный текст.

---

### 3. Просмотр текущего трека и статуса
Узнать, что сейчас играет на колонке:
```bash
python get_speaker_state.py
```
Скрипт покажет:
- Статус плеера (играет / на паузе)
- Уровень громкости
- Текущий трек и исполнителя
- Прямую ссылку на обложку альбома
- Состояние голосового ассистента

## Использование в своих проектах

Вы можете отправлять команды на колонку напрямую из своего Python-кода:

```python
import asyncio
import json
import ssl
import time
import uuid
import websockets

async def send_command(ip: str, glagol_token: str, text: str):
    ssl_context = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
    ssl_context.check_hostname = False
    ssl_context.verify_mode = ssl.CERT_NONE

    async with websockets.connect(f"wss://{ip}:1961", ssl=ssl_context) as ws:
        payload = {
            "conversationToken": glagol_token,
            "id": str(uuid.uuid4()),
            "sentTime": int(round(time.time() * 1000)),
            "payload": {
                "command": "sendText",
                "text": text
            }
        }
        await ws.send(json.dumps(payload))

# Пример: сказать фразу через колонку
# asyncio.run(send_command("192.168.1.50", "ВАШ_GLAGOL_TOKEN", "Привет, мир!"))
```
