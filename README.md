# Yandex Station Local Control API

Простая и эффективная реализация локального управления умными колонками Яндекса (Станциями) через протокол **Glagol**. Позволяет управлять плеером, изменять громкость и отправлять текстовые команды (TTS) без использования облака.

## Возможности
- **Автоматическая авторизация**: Получение OAuth-токена через QR-код.
- **Локальный поиск**: Обнаружение устройств в сети по протоколу mDNS (Zeroconf).
- **Мониторинг**: Получение статуса в реальном времени (громкость, текущий трек, обложка альбома).
- **Управление плеером**: Play/Pause, Next/Prev треки, установка громкости.
- **TTS (Text-to-Speech)**: Отправка любого текста для озвучки Алисой.

## Быстрый старт
1. **Установка зависимостей**:
   ```bash
   pip install requests websockets zeroconf
   ```
2. **Первоначальная настройка**:
   ```bash
   python yandex_setup_full.py
   ```
   Отсканируйте QR-код и получите токены ваших устройств.

3. **Управление музыкой**:
   ```bash
   python test_music_control.py
   ```

4. **Получение статуса (что играет)**:
   ```bash
   python get_speaker_state.py
   ```

## Структура проекта
- `yandex_setup_full.py` — мастер-скрипт настройки и получения ключей.
- `test_music_control.py` — интерактивный пульт управления (треки, громкость).
- `get_speaker_state.py` — мониторинг состояния колонки и метаданных треков.
- `.env` — хранение OAuth-токена (создается автоматически, игнорируется Git).
- `glagol_tokens.json` — кэш данных устройств (создается автоматически, игнорируется Git).
