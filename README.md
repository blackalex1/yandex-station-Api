# Yandex Station Local Control API

Простая и эффективная реализация локального управления умными колонками Яндекса (Станциями) через протокол **Glagol**. Позволяет отправлять текстовые команды (TTS) и управлять плеером без использования облачных сценариев.

## Возможности
- **Автоматическая авторизация**: Получение OAuth-токена через QR-код (имитация мобильного приложения).
- **Локальный поиск**: Обнаружение устройств в сети по протоколу mDNS (Zeroconf).
- **Прямое управление**: Получение локальных Glagol-токенов и отправка команд напрямую на IP-адрес колонки.
- **Минимальные зависимости**: Используются только `requests`, `websockets` и `zeroconf`.

## Быстрый старт
1. **Установка зависимостей**:
   ```bash
   pip install requests websockets zeroconf
   ```
2. **Запуск мастера настройки**:
   ```bash
   python yandex_setup_full.py
   ```
3. **Авторизация**: Перейдите по сгенерированной ссылке и отсканируйте QR-код приложением Яндекса.
4. **Тестирование**: После успешного получения токенов выберите колонку из списка для проверки связи.

## Структура проекта
- `yandex_setup_full.py` — единый скрипт для авторизации, поиска и тестирования.
- `.env` — файл для хранения вашего `YANDEX_TOKEN` (создается автоматически).
- `glagol_tokens.json` — кэш с данными ваших устройств (создается автоматически).

## Безопасность
Файлы `.env` и `glagol_tokens.json` содержат конфиденциальные данные и **исключены из репозитория** через `.gitignore`. Никогда не передавайте их третьим лицам.
